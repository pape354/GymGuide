# GymGuide
A mobile app built with Unity that helps users find exercises and build custom workouts.

## App Purpose
GymGuide allows users to browse exercises by muscle group, select exercises for their workout, and view their custom workout plan.

## Features
- Browse exercises by muscle group (Chest, Back, Legs, Shoulders, Arms)
- Select up to 5 exercises for a custom workout
- Exercise counter shows progress (0/5 added)
- Workout scene displays all selected exercises
- Clear workout and start over

## Scenes
- **SplashScene** — App intro with Get Started button
- **HomeScene** — Welcome screen with quick access
- **SearchScene** — Browse and filter exercises
- **DetailScene** — Exercise details and steps
- **WorkoutScene** — View your selected workout

## How to Run
1. Open Unity Hub
2. Open the GymGuide project
3. Press Play in the Unity Editor

## Built With
- Unity 6.3 LTS
- C#
- Android Build Support
